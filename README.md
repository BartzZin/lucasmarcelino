# Currículo de Lucas Marcelino Lara

Página pessoal em português com experiência, formação e projetos. [Acessar o currículo](https://bartzzin.github.io/lucasmarcelino/).

## Plano de implementação

| Etapa | Decisão e critério de aceite |
| --- | --- |
| Selecionar o conteúdo | Usar o LinkedIn para experiência e formação. Vincular cada projeto ao repositório que demonstra o trabalho. |
| Organizar a leitura | Abrir com nome e atuação na Consisa Sistemas. Apresentar trajetória, tecnologias, projetos e arquivo cronológico de 2023 a 2026. Encerrar com contato direto pelo WhatsApp. |
| Construir a interação | Animar quatro peças com acabamento 3D e órbitas luminosas. Dar a cada peça sua própria rotação e trajetória. Usar a rolagem para aproximar e afastar os encaixes, preservando uma fresta entre as peças. |
| Adaptar e testar | Animar o quebra-cabeça 3D sobre a página, com a posição guiada pelos capítulos. No desktop, alternar os lados da leitura. No celular, levar a montagem da abertura à margem do texto. Verificar movimento automático na abertura e ao percorrer os capítulos. Testar âncoras, leitura por teclado, impressão, estado final e preferência por movimento reduzido. |
| Publicar e manter | Servir arquivos estáticos pelo GitHub Pages a partir da raiz da branch main. Conferir a URL pública e revisar o currículo quando houver mudança profissional ou novo projeto representativo. |

O arquivo `puzzle.js` anima cada peça e desenha as órbitas. O arquivo `scroll.js` acompanha o progresso da leitura. O site dispensa instalação de dependências.
